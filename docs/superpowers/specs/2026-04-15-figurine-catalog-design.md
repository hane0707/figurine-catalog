# フィギュア・コレクション管理サイト — 設計仕様書

**作成日:** 2026-04-15  
**ステータス:** 承認済み

---

## 概要

フィギュアや置物などのコレクションを写真と一緒に記録・管理するWebアプリケーション。個人利用を主とし、必要に応じて公開もできる。「写真1枚で即保存 → あとで詳細を追記」という2段階登録と、購入品/自作品で分岐するウィザード形式UIが核心。

---

## ユーザーと公開設定

- **主用途:** 個人のコレクション管理（シングルユーザー）
- **公開機能:** アイテム単位で公開/非公開を切り替え可能（`is_public` フラグ）
- **認証:** Cloudflare Access による保護（非公開コンテンツへのアクセス制御）

---

## 技術スタック

| レイヤー | 採用技術 |
|---|---|
| フロントエンド | SvelteKit（`@sveltejs/adapter-cloudflare`） |
| ホスティング | Cloudflare Pages |
| APIサーバー | Cloudflare Workers（SvelteKit server routesが自動的にWorkerになる） |
| データベース | Cloudflare D1（SQLite） |
| 写真ストレージ | Cloudflare R2 |
| 画像リサイズ | Cloudflare Image Resizing（サムネイル生成） |
| 認証 | Cloudflare Access |

## 写真フロー

1. ユーザーが写真を選択（カメラ撮影またはライブラリ）
2. Workers経由でR2に元画像をアップロード（キー: `items/{item_id}/{uuid}.jpg`）
3. サムネイルはCloudflare Image ResizingでURL変換して配信（別途保存不要）
4. `photos` テーブルにr2_keyを記録

## UI/UX設計

### クイック登録フロー

```
① 写真を選択（1枚以上）
    ↓
② そのまま保存（名前・詳細は全てスキップ可）
    ↓ ← ここで完了してもよい
③ 詳細ウィザードへ（任意）
```

最小操作: 写真を選んで保存ボタンを押すだけ。

### 詳細入力ウィザード（分岐フロー）

```
STEP 1: 写真の確認・追加
STEP 2: 名前・シリーズ名（スキップ可）
STEP 3: 購入品 / 自作品 を選択 ← 分岐点
    ┌── 購入品 ──────────────────────────────┐
    │ STEP 4: 購入情報                        │
    │   - 店舗名 / ECサイト名                 │
    │   - イベント名                          │
    │   - 購入日 / 購入金額                   │
    │   - メーカー名 / 作家名・原型師名        │
    └─────────────────────────────────────────┘
    ┌── 自作品 ──────────────────────────────┐
    │ STEP 4: 制作情報                        │
    │   - 制作開始日 / 完成日                 │
    │   - 素材・ツール（タグピッカー）         │
    │   - 制作メモ・塗装記録（自由記述）       │
    └─────────────────────────────────────────┘
STEP 5（共通）: タグを設定して完了
```

全ステップにスキップボタンあり。ウィザードを途中で閉じた場合でも、写真保存済みであればアイテムはすでにDBに存在するため、一覧から再度開いて詳細を追記できる（ドラフト状態は持たない）。

### 素材・ツール タグピッカー

- **よく使うもの:** ユーザーの過去登録を集計し上位4〜6件を優先表示
- **定番リスト:** アプリ初期データとして素材（石粉粘土・エポキシパテ・スカルピー・レジン・ポリパテ・プラ板・真鍮線 等）とツール/塗料（エアブラシ・筆塗り・缶スプレー・水性アクリル塗料・Mr.カラー・ラッカー塗料・ウォッシング・デカール・3Dプリンター・ルーター 等）を収録
- **カスタム追加:** 自由入力で新素材を追加 → 以降の候補に自動追加
- **実装:** 汎用 `TagPicker` Svelteコンポーネントとして実装し、アイテムタグでも同じものを再利用

### コレクション一覧

- グリッド表示（固定幅カード、縦横比 3:4）
- カード: カバー写真 + アイテム名（未設定は「名称未設定」と表示）
- タグフィルタ: 画面上部にタグ一覧、複数選択時はOR絞り込み
- FAB（フローティングアクションボタン）でクイック登録起動

---

## 非機能要件

- 写真アップロード: 1ファイル最大20MB、JPG/PNG/WEBP対応
- サムネイル: 400px幅でCloudflare Image Resizingにより動的生成
- レスポンシブ: モバイルファースト設計（スマートフォンでの撮影→即登録を想定）
- オフライン: 対応しない（Cloudflare Workersへの接続必須）
