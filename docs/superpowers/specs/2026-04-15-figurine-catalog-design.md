# フィギュア・コレクション管理サイト — 設計仕様書

**作成日:** 2026-04-15  
**ステータス:** 承認済み（grill-me セッションにて詳細確定）

---

## 概要

フィギュアや置物などのコレクションを写真と一緒に記録・管理するWebアプリケーション。個人利用を主とし、必要に応じてアイテム単位で公開もできる。「写真1枚で即保存 → あとで詳細を追記」という2段階登録と、購入品/自作品で分岐するウィザード形式UIが核心。

---

## ユーザーと公開設定

- **主用途:** 個人のコレクション管理（シングルユーザー）
- **公開機能:** アイテム単位で公開/非公開を切り替え可能（`is_public` フラグ）
- **公開URL形式:** `/p/{uuid}`（Cloudflare Accessの保護対象外パス）
- **認証:** Cloudflare Access + Googleログイン。`/p/*` は全員アクセス可、それ以外は認証必須

## 写真フロー

1. クライアントがアイテムUUIDを生成
2. Workerに presigned URL 発行を要求（元画像用・サムネイル用の2つ）
3. クライアントがCanvas APIで400px幅WebPサムネイルを生成
4. ブラウザが元画像・サムネイルを並列でR2に直接PUT
5. 失敗時は最大3回自動リトライ。3回失敗でエラートースト表示
6. アップロード完了後、Workerが `photos` テーブルにr2_keyを記録
7. 写真の表示: 非公開アイテムは署名付きURL（1時間有効）で配信。公開アイテムはR2公開URL

**R2キー命名規則:**
- 元画像: `items/{item_id}/orig_{photo_id}.jpg`
- サムネイル: `items/{item_id}/thumb_{photo_id}.webp`

## UI/UX設計

### クイック登録フロー

```
① 写真を複数枚まとめて選択（1枚以上）
    ↓
② そのまま保存（名前・詳細は全てスキップ可）
    ↓ ← ここで完了してもよい
③ 詳細ウィザードへ（任意）
```

最小操作: 写真を選んで保存ボタンを押すだけ。ウィザードを途中で閉じた場合でも、アイテムはすでにDBに存在するため、一覧から再度開いて詳細を追記できる（ドラフト状態は持たない）。

### 詳細入力ウィザード（分岐フロー）

```
STEP 1: 写真の確認・追加（最大20枚、ドラッグ&ドロップで並び替え）
STEP 2: 名前・シリーズ名（スキップ可）
STEP 3: 購入品 / 自作品 を選択 ← 分岐点
    ┌── 購入品 ──────────────────────────────┐
    │ STEP 4: 購入情報                        │
    │   - 店舗名 / ECサイト名                 │
    │   - イベント名                          │
    │   - 購入日 / 購入金額                   │
    │   - メーカー名 / 作家名・原型師名        │
    └─────────────────────────────────────────┘
    ┌── 自作品 ──────────────────────────────┐
    │ STEP 4: 制作情報                        │
    │   - 制作開始日 / 完成日                 │
    │   - 素材・ツール（タグピッカー）         │
    │   - 制作メモ・塗装記録（自由記述）       │
    └─────────────────────────────────────────┘
STEP 5（共通）: タグを設定して完了
```

全ステップにスキップボタンあり。

### 素材・ツール タグピッカー

- **よく使うもの:** ユーザーの過去登録を集計し上位4〜6件を優先表示
- **定番リスト:** 素材（石粉粘土・エポキシパテ・スカルピー・レジン・ポリパテ・プラ板・真鍮線 等）とツール/塗料（エアブラシ・筆塗り・缶スプレー・水性アクリル塗料・Mr.カラー・ラッカー塗料・ウォッシング・デカール・3Dプリンター・ルーター 等）を収録
- **カスタム追加:** 自由入力で新素材を追加 → 以降の候補に自動追加
- **実装:** 汎用 `TagPicker` Svelteコンポーネントとして実装し、アイテムタグでも同じものを再利用

### コレクション一覧

- グリッド表示（固定幅カード、縦横比 3:4）
- デフォルト並び順: 登録日の新しい順（created_at DESC）
- カード: カバー写真 + アイテム名（未設定は「名称未設定」と表示）
- タグフィルタ: 画面上部にタグ一覧、複数選択時はOR絞り込み
- キーワード検索: 名前・シリーズ名・作家名をLIKE検索
- ページング: 無限スクロール（1回あたり30件読み込み）
- デフォルト表示: `status = 'owned'` のみ。「手放したもの」は切り替えで表示
- FAB（フローティングアクションボタン）でクイック登録起動

### アイテム詳細・編集

- 専用ページ（`/items/{id}`）
- 表示と編集は同じページ内でインライン編集（編集モードボタンで切り替え）
- 削除時: 確認ダイアログ → DBレコード + R2ファイルを即時削除

## 非機能要件

- 写真アップロード: 1ファイル最大20MB、JPG/PNG/WEBP対応、1アイテムあたり最大20枚
- サムネイル: クライアントサイドで400px幅WebPに変換してからアップロード
- レスポンシブ: モバイルファースト設計
- PWA: manifest + Service Worker（ホーム画面追加対応）
- オフライン: 対応しない
- 写真アップロード失敗時: 最大3回自動リトライ後にエラートースト
